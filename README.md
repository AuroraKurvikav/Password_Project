# Генератор паролей (Password Generator)

## Краткое описание программного обеспечения
Данное программное обеспечение представляет собой консольную программу на языке Python, предназначенную для генерации надежных случайных паролей. Программа позволяет пользователю задавать длину пароля и выбирать, использовать ли специальные символы.

## Инструкция по установке
1. Установите Python версии 3.8 или выше.
2. Скачайте файл `password_generator.py` из данного репозитория.
3. Убедитесь, что у вас установлены стандартные библиотеки `random` и `string` (они встроены в Python по умолчанию).

## Инструкция по сборке и запуску
1. Откройте командную строку (терминал).
2. Перейдите в папку с файлом `password_generator.py`.
3. Запустите программу командой:
   `python password_generator.py`
4. Следуйте инструкциям в консоли (введите длину и подтвердите использование спецсимволов).

## Документация
- `generate_password(length, use_special_chars)` — основная функция генерации, принимает длину пароля и булево значение (нужны ли спецсимволы).
- `main()` — функция интерфейса, отвечающая за ввод данных пользователем и вывод результата.
